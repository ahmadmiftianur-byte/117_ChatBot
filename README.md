# NeMo Assistant – Chatbot AI

## 1. Deskripsi Project

NeMo Assistant merupakan aplikasi chatbot berbasis web yang dikembangkan menggunakan **Node.js dan Express.js**. Aplikasi ini memungkinkan pengguna untuk berinteraksi dengan Artificial Intelligence (AI) melalui tampilan website yang sederhana, modern, dan mudah digunakan.

Chatbot ini menggunakan **OpenRouter API** sebagai penghubung ke model AI sehingga pengguna dapat mengirimkan pertanyaan dan memperoleh jawaban secara otomatis.

Project ini dibuat untuk memenuhi tugas praktikum mata kuliah Pemrograman Web dengan membuat program chatbot menggunakan Express.js yang dilengkapi tampilan web.

## 2. Tujuan Project

Tujuan pembuatan aplikasi NeMo Assistant adalah:

- Menerapkan penggunaan Node.js dan Express.js dalam pengembangan aplikasi web.
- Mengintegrasikan API AI menggunakan OpenRouter.
- Membuat antarmuka chatbot menggunakan HTML, CSS, dan JavaScript.
- Memahami komunikasi antara frontend dan backend.
- Menerapkan fitur pengiriman dan penerimaan pesan secara streaming.

## 3. Teknologi yang Digunakan

Teknologi dan tools yang digunakan dalam project ini meliputi:

| Teknologi | Kegunaan |
|---|---|
| HTML | Membuat struktur halaman website |
| CSS | Mengatur tampilan dan desain chatbot |
| JavaScript | Mengatur interaksi dan komunikasi frontend |
| Node.js | Menjalankan JavaScript di sisi server |
| Express.js | Membuat server dan API chatbot |
| OpenRouter API | Menghubungkan aplikasi dengan model AI |
| GitHub | Menyimpan dan mengelola source code |
| Vercel | Melakukan deployment aplikasi |

## 4. Fitur Aplikasi

NeMo Assistant memiliki beberapa fitur utama, yaitu:

1. **Chat dengan AI**  
   Pengguna dapat mengirimkan pertanyaan dan mendapatkan jawaban dari AI.

2. **Streaming Response**  
   Jawaban AI ditampilkan secara bertahap sehingga pengguna tidak perlu menunggu seluruh jawaban selesai dibuat.

3. **Riwayat Percakapan**  
   Pesan pengguna dan jawaban AI disimpan selama sesi percakapan berlangsung agar konteks pembicaraan tetap terjaga.

4. **Percakapan Baru**  
   Pengguna dapat memulai percakapan baru dengan menghapus riwayat percakapan sebelumnya.
